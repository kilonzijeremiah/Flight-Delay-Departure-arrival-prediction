# Flight Delay Predictor

A machine learning web app that predicts **Departure Delay** and **Arrival Delay** for flights.

## Features
- Predict departure delay
- Predict arrival delay (uses departure delay when available)
- Clean and simple user interface
- Built with Streamlit + HistGradientBoosting

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
